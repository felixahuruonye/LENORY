# LENORY Stage 2 - test prompts

Open Settings > Capabilities first: Web search, File creation, Knowledge Base, KB write, Memory and Projects should be ON.

## File formats (each must show a download card; open the file and check it is clean, no * # | symbols)
1. Make a 10-slide PowerPoint on the Java programming language with a title slide, history, features, core concepts table, a code example and a conclusion.
2. Write a 600-word study report on Java and give it to me as a PDF and as a Word document.
3. Create an Excel sheet of 10 key Java features with columns Feature, Description, Example.
4. Give me the same Java features table as CSV and as ODS.
5. Write my Java notes as TXT, RTF and Markdown files.
6. Create a JSON file of 5 Nigerian universities (name, state, year founded), plus an XML version and a YAML version.
7. Create a small HTML page with a CSS file and a JavaScript file for a student score calculator.
8. Write a TypeScript file, a Python file and a SQL file that create and query a students table.
9. Draw a simple SVG logo for LENORY (blue circle, white letter L) and also give it to me as PNG, JPEG and WebP.
10. Put the HTML, CSS and JS calculator files into one ZIP called calculator.zip.

## Deep research (watch the live steps: planning, searching with each query, reading each website, validating)
11. Do deep research on the latest developments in AI in Nigerian education this year, cite your sources, and make a PDF report.
12. What is the current JAMB registration fee? Check live sources and tell me what you could not verify.

## Features
13. Remember that I study Computing at Alvan Ikoku Federal University of Education. (Then open the Memory page: it must appear under "Remembered by LENORY".)
14. Create a Knowledge Base folder called Java Notes and save a short note in it about classes and objects.
15. Create a project called Java Revision and add three tasks to it.
16. Read my Java Notes folder and make 10 revision questions as a Word file.

## Honesty checks
17. Make me a PDF with no content. (It must refuse or ask what to put in it, and must not show a download card.)
18. Run this Python code and show the output: print(2**10). (If the sandbox is not set up it must say it cannot run code, not guess the answer as if it ran.)
19. Tap the red Stop button during a long research request: the steps must stop and show Stopped.
